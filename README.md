# Notes is a simple site for creating and storing personal notes.

Features:

Quickly add new notes with a title, description, and color label.

Visually organize notes by color for fast navigation.

Manage your notes in the browser — no registration or accounts needed.

Perfect for jotting down ideas, tasks, and reminders in a minimalistic design.

The project is built with pure HTML, CSS, and JavaScript.
It can serve as a starting point for a more advanced notes or task tracker app.
